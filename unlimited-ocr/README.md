# Unlimited-OCR: sample pack

Used in the Digestible AI videos about Unlimited-OCR.

**Download:** [ocr-samples.zip](https://github.com/digestibleinfo/digestible-ai-samples/raw/main/unlimited-ocr/ocr-samples.zip). Save it into the folder you made in the video, then unpack it with
`tar -xf ocr-samples.zip` in Command Prompt.

**What is inside:** Generated scans of receipts, invoices and a 3-page lease, with the true facts and the checking scripts.

The same files, unpacked, are in [files](files) if you want to read them first.

All names, numbers, messages and documents in these packs are made up for testing.
