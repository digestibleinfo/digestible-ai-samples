# Open WebUI + Ollama: sample pack

Used in the Digestible AI videos about Open WebUI + Ollama.

**Download:** [openwebui-samples.zip](https://github.com/digestibleinfo/digestible-ai-samples/raw/main/openwebui/openwebui-samples.zip). Save it into the folder you made in the video, then unpack it with
`tar -xf openwebui-samples.zip` in Command Prompt.

**What is inside:** 11 made-up documents (10 invoices and a lease), 14 questions with known answers, and rag_test.py.

The same files, unpacked, are in [files](files) if you want to read them first.

All names, numbers, messages and documents in these packs are made up for testing.
