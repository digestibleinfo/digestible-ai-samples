# MiniCPM5-2B: sample pack

Used in the Digestible AI videos about MiniCPM5-2B.

**Download:** [minicpm-samples.zip](https://github.com/digestibleinfo/digestible-ai-samples/raw/main/minicpm5-2b/minicpm-samples.zip). Save it into the folder you made in the video, then unpack it with
`tar -xf minicpm-samples.zip` in Command Prompt.

**What is inside:** Test scripts for maths, invoice reading, small coding jobs and a long made-up staff handbook, plus a Transformers speed test.

The same files, unpacked, are in [files](files) if you want to read them first.

All names, numbers, messages and documents in these packs are made up for testing.
