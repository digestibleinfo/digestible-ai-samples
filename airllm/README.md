# AirLLM: sample pack

Used in the Digestible AI videos about AirLLM.

**Download:** [airllm-samples.zip](https://github.com/digestibleinfo/digestible-ai-samples/raw/main/airllm/airllm-samples.zip). Save it into the folder you made in the video, then unpack it with
`tar -xf airllm-samples.zip` in Command Prompt.

**What is inside:** first_try.py (one prompt) and batch_test.py (8 questions with known answers in one batch).

The same files, unpacked, are in [files](files) if you want to read them first.

All names, numbers, messages and documents in these packs are made up for testing.
