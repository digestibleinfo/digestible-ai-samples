# EmbeddingGemma 2: sample pack

Used in the Digestible AI videos about EmbeddingGemma 2.

**Download:** [embedding-samples.zip](https://github.com/digestibleinfo/digestible-ai-samples/raw/main/embeddinggemma/embedding-samples.zip). Save it into the folder you made in the video, then unpack it with
`tar -xf embedding-samples.zip` in Command Prompt.

**What is inside:** 30 made-up documents, 20 AI-generated photos, 12 synthetic voice notes and the search scripts.

The same files, unpacked, are in [files](files) if you want to read them first.

All names, numbers, messages and documents in these packs are made up for testing.
