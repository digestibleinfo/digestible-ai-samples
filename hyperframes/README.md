# Hyperframes: sample pack

Used in the Digestible AI videos about Hyperframes.

**Download:** [hyperframes-samples.zip](https://github.com/digestibleinfo/digestible-ai-samples/raw/main/hyperframes/hyperframes-samples.zip). Save it into the folder you made in the video, then unpack it with
`tar -xf hyperframes-samples.zip` in Command Prompt.

**What is inside:** first_try.html (the draft that fails the layout check) and index.html (the fixed one).

The same files, unpacked, are in [files](files) if you want to read them first.

All names, numbers, messages and documents in these packs are made up for testing.
