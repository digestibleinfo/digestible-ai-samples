# OpenJev (Jev decision model) with llama.cpp: sample pack

Used in the Digestible AI videos about OpenJev (Jev decision model) with llama.cpp.

**Download:** [jev-samples.zip](https://github.com/digestibleinfo/digestible-ai-samples/raw/main/openjev/jev-samples.zip). Save it into the folder you made in the video, then unpack it with
`tar -xf jev-samples.zip` in Command Prompt.

**What is inside:** ask.py, decide.py, run_tests.py and 55 made-up test decisions (scams, expenses, urgency, support tickets, comments) with known answers.

The same files, unpacked, are in [files](files) if you want to read them first.

All names, numbers, messages and documents in these packs are made up for testing.
